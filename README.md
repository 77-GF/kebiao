# 我的课表 📅

一个可以装到手机桌面的大学课表（PWA 网页应用）。支持周/日两种视图、单双周、手动录入课程（课程名称 / 教师 / 教室 / 节次 / 星期），数据存在手机本地，离线也能用。

## 功能

- **日视图 / 周视图** 一键切换
- **手动录入**：点右下角 `＋` 或直接点课表空格子即可添加，字段含「课程名称、教师、教室、星期、起止节次、周次、颜色、备注」
- **按具体周次排课**：每门课可指定它上哪几周 —— 支持「每周 / 单周 / 双周 / 自定义（如 `1-8`、`1,3,5`、`1-8,10-16`）」，课程随周变化也能精确表达
- **第 N 周切换器**：顶部 `◀ 第 N 周 ▶` 左右切周，看哪周就是哪周的课；点周次数字可直接跳转
- **今天高亮**：自动定位今天，标出当前正在上的节次；顶部「今天」按钮一键回到本周
- **数据本地存储**（浏览器 localStorage），刷新不丢
- **导出 / 导入 JSON 备份**
- **可安装到手机桌面**，像独立 App 一样打开（全屏、有图标）

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 主应用（所有界面和逻辑都在里面） |
| `manifest.webmanifest` | PWA 配置（应用名、图标、全屏模式） |
| `sw.js` | Service Worker，离线缓存 |
| `icons/` | 应用图标（192/512） |

## 怎么在电脑上先跑起来

直接双击 `index.html` 也能打开使用（数据存本机浏览器）。但要让「添加到主屏幕」生效，需要通过 HTTP 访问（不是 file://）。

任选一种方式启动本地服务器：

```bash
# 方式一：Python（推荐，Windows 一般都有）
cd D:\AI\kebiao
python -m http.server 8000
```

然后在电脑浏览器打开 `http://localhost:8000` 即可看到并录入课表。

## 怎么装到手机桌面（安卓）

手机和电脑连**同一个 WiFi**，按下面步骤：

1. 电脑上启动服务器（见上），并查电脑局域网 IP：
   ```bash
   ipconfig   # Windows 里找「IPv4 地址」，例如 192.168.1.100
   ```
2. 手机 Chrome 打开 `http://192.168.1.100:8000`
3. 点浏览器右上角 **⋮ → 添加到主屏幕 / 安装应用**
4. 桌面出现「我的课表」图标，点开即全屏 App 体验

> 更省事、永久的方案：把 `index.html`、`manifest.webmanifest`、`sw.js`、`icons/` 一起推到 **GitHub Pages**，就能得到一个 `https://` 网址，手机随时打开、随时添加到桌面，不依赖电脑和同一 WiFi。需要的话我可以帮你配。

## 使用小贴士

- **录入**：点 `＋` 添加课程；在周视图里直接点空白格子会自动带上那天和那节次。
- **指定周次**：录入时「周次」一栏选「自定义」，输入 `1-8` 表示第 1 到 8 周上，`1,3,5` 表示第 1、3、5 周上，`1-8,10-16` 表示两段；「单周 / 双周」是快捷方式。
- **改节次时间**：菜单 `⋮ → 节次时间设置`，默认按常见大学作息（第1节 08:00 起），可按你学校改。
- **自动算周**：菜单 `⋮ → 设置开学日期`（填某周一的日期），顶部会自动定位到「本周」并显示「第 N 周」。
- **总周数**：菜单 `⋮ → 本学期总周数`（默认 20），影响单双周展开和周次跳转范围。
- **备份**：菜单 `⋮ → 导出备份`，换手机时 `导入备份` 即可恢复。
